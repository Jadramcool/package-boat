网页端接收页 · 排版重设计 PB-WEB-01

当前接收页是「统计条 → 关于折叠 → 拖放区 → 队列 → 文件架」的单列瀑布， 宽屏大量横向空间闲置，文件架被挤到首屏之外。本方案改成 主列工作区 + 右侧连接栏，把「投递 / 传输 / 拿文件」放在同一视野， 二维码与会话信息常驻侧栏（与桌面端 PB-UI-04 同构）。

现状：单列堆叠 方案：双栏工作区 视觉 token 沿用 PB-UI-01 手机单列降级

  • 44+ 文件架标题行

方案（≥1100px）

  • 52 AppHeader（在线态改 info 蓝，语义对齐桌面）
  • 主列 拖放单行条（酸绿主行动）
  • 主列 传输队列（仅活动任务）
  • 主列 文件架 —— 垂直空间全给列表
  • 侧栏 扫码接入（QR 128 + 地址）
  • 侧栏 本机会话（统计 + 断开）
